# 画布分组功能（Group）

> 分支：`perf/canvas-lod`（基于 LOD 提交 83654cc）

### 🎯 目标理解（需求确认）

- **框选**：Ctrl + 拖拽框选（已有：`selectionRect` + `findNodesInSelectionRect`）。
- **点选切换**：Ctrl + 左键点节点 → 加入/移出选中（新增；现有是 Ctrl 框选，无点选 toggle）。
- **右键菜单**：选中状态下右键 → 显示「添加分组」按钮（替代当前的添加节点菜单 `addMenu`）；未选中则维持原 `addMenu`。
- **分组**：默认名「分组」；双击分组名 / 分组按钮 → 编辑名称。
- **样式**：淡黑色半透明背景 + 略突出的边框。
- **节点移动**：分组内节点可自由移动；节点移出 → 分组矩形扩大到包含所有节点。
- **分组缩放**：分组右下角 handle 缩放。
- **分组拖拽**：分组内空余区域左键拖拽 → 移动整个分组（含内部所有节点）。

### 🧠 分析与思考

- **数据模型**：`CanvasView` 增 `groups: CanvasGroupView[]`。
  - `CanvasGroupView = { id: string; name: string; nodeIds: string[]; bounds?: Bounds }`
  - `bounds` 可选（手动缩放/拖拽设定的固定框）；**实际渲染 bounds = 包含所有 `nodeIds` 节点的并集 ∪ 可选手动 bounds**（取并集 → 节点移出永远包含）。
- **持久化兼容**：旧数据无 `groups` → 反序列化默认 `[]`；`isCanvasView` 校验放宽（groups optional）。
- **渲染层级**：分组矩形绝对定位，**节点下层**（z-index 低于节点），位于画布内容层（与节点同坐标系，随 viewport transform）。
- **Ctrl+左键点选 toggle**：`handleNodePointerDown` 检查 `event.ctrlKey || event.metaKey` → toggle 该节点选中（而非替换选中）；非 Ctrl 维持现有（替换选中 + 拖拽）。
- **右键分流**：`onContextMenu`：若 `selectedNodeIds.length > 0` → 显示「分组菜单」（含「添加分组」）；否则 → 现有 `addMenu`。
- **自适应 bounds**：节点 move/resize 后，依赖该节点的分组重算渲染 bounds（memo，按 group 的 nodeIds 取节点并集）。**只扩不缩**（节点移入不收缩，避免抖动；见待确认）。
- **分组缩放**：右下角 handle 拖拽 → 改 `bounds`（手动）。节点超出仍扩大渲染 bounds。
- **分组拖拽**：分组背景空区域 pointerdown → 「移动分组」模式，拖拽 delta 同时应用到 `bounds` 与所有内部节点坐标。
- **并发/副作用**：纯前端状态，无并发；分组拖拽批量移动节点需一次 setState。

### 🚨 风险评估与回滚

- **数据模型变更**：`CanvasView.groups` optional，旧数据兼容（默认 `[]`）；反序列化容错。
- **交互冲突**：分组拖拽 vs 节点拖拽 vs 画布平移 —— pointerdown 命中优先级（分组背景空区域 vs 节点 vs 画布）。
- **右键分流**：与现有 `addMenu`（添加节点）冲突 —— 按「是否选中」分流。
- **bounds 重算性能**：分组多/节点多时，memo 化（按 group nodeIds）。
- **分组拖拽批量移动**：大量节点一次 setState（性能 + 撤销栈）。
- **缩放/收缩语义**：见待确认。
- **回滚**：`groups` optional + 渲染/交互可 feature-flag 关闭；数据模型向后兼容，单提交 revert。

### Code Review（模拟苛刻审查）

- ⚠️ **分组拖拽移动内部节点**：N 个节点坐标 +N delta，需一次 setState（批量），否则多次渲染卡顿。
- ⚠️ **bounds 只扩不缩**：节点移入不收缩 → 分组只会变大。若用户想缩小需手动缩放 handle（设新 bounds）。需确认符合预期。
- ⚠️ **Ctrl+点击 vs Ctrl+拖拽**：Ctrl+点击（无拖拽）= toggle 选中；Ctrl+拖拽空白 = 框选。需 pointermove 阈值区分（避免点击被误判框选）。
- ⚠️ **右键分流**：选中状态下右键空白 vs 右键节点 —— 需一致（都显示分组菜单？）。
- ⚠️ **分组与 LOD**：LOD 简化模式下分组矩形仍应显示（分组是结构，不应随节点简化消失）。
- ✅ 数据模型 optional，向后兼容。

### ❓ 待确认问题

1. **缩放语义**：右下角缩放是设分组「最小 bounds」（节点超出仍扩大）还是「固定 bounds」（节点超出也不扩）？—— 倾向前者（最小 bounds + 节点超出扩大）。
2. **分组收缩**：节点移入分组内时，分组是否收缩？还是**只扩不缩**（推荐，避免抖动）？
3. **嵌套**：分组内可再建分组？
4. **删除分组**：如何触发？删后节点保留（仅取消分组归属）？
5. **最小闭环**：先做阶段 1（创建+渲染+自适应）验证，还是一次做全（含编辑/拖拽/缩放）？
