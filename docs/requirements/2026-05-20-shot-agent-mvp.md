# shot-agent MVP 需求文档

日期：2026-05-20

## 目标

`shot-agent` 第一阶段目标是提供一个干净、简洁的无限画布，让用户可以在画布中组织图片、视频和大模型节点，并把每次生成过程、工作流配置和生成资产稳定保存在本地项目目录中。

第一期重点支持：

- 画布管理
- 供应商管理
- 画布内工作流管理
- 图片节点：`gpt-image-2`
- 视频节点：`seedance2.0` / `seedance2.0-fast`
- 对话节点：OpenAI 格式或 Anthropic 格式语言模型

## 参考文档

- [AGENTS.md](../../AGENTS.md)
- [OpenAI / gpt-image-2](../external-api/image/openai/gpt-image-2.md)

- OpenAI 图片编辑 API 文档说明：GPT image models 编辑输入最多支持 16 张图片。

## 术语

- 画布：一个独立创作项目，包含节点、连线、工作流配置、提示词、生成记录和资产。
- 画布文件夹：一个画布对应一个本地文件夹，保存该画布产生的全部内容。
- 资产：图片、视频、文件等可被节点引用的内容。
- 节点：画布中的可执行或展示单元，例如图片节点、视频节点、对话节点。
- 工作流：节点、连线、执行参数、输入输出引用关系组成的配置。
- 供应商：OpenAI、火山方舟、第三方 OpenAI-compatible 网关等模型调用通道。
- 模型映射：供应商侧模型 ID 到项目标准模型 ID 的映射，例如供应商支持 `image-2`，映射为项目节点使用的 `gpt-image-2`。

## 一期范围

一期必须完成：

- 新建、命名、删除、导入、导出画布。
- 每个画布一个文件夹，文件夹内保存工作流、提示词、生成资产、生成历史。
- 供应商配置列表，支持 `baseURL`、`apiToken`、模型列表和模型映射。
- 供应商连通性测试。
- 图片节点、视频节点、对话节点。
- 节点生成后自动保存工作流快照和输出资产。
- 支持节点多次触发生成，并保留历史版本。
- 支持任务失败重试，默认最多 3 次，可关闭。
- 支持本地存储，云端存储优先 Cloudflare R2。

一期暂不做：

- 分支控制、循环控制。
- 多人协作。
- 复杂权限系统。
- 独立模型能力声明系统。
- 复杂项目迁移工具。使用相对路径天然支持简单迁移。

## 画布管理

### 新建画布

用户可以新建画布。新建时需要：

- 输入画布名称。
- 选择画布文件夹保存位置。
- 系统生成随机唯一 ID 作为画布唯一标识。
- 在目标位置创建画布文件夹。

画布允许同名。唯一性由随机 ID 保证，不依赖画布名称。

### 画布文件夹结构

建议结构：

```text
<canvas-folder>/
  canvas.json              # 画布元数据、节点布局、当前工作流引用
  workflow.json            # 当前工作流配置
  history/
    generations.jsonl      # 每次生成记录
    workflow-snapshots/    # 每次生成时的工作流快照
  prompts/
    prompts.jsonl          # 提示词历史
  assets/
    images/                # 生成或导入的图片
    videos/                # 生成或导入的视频
    files/                 # 其他文件
    covers/                # 视频封面
  exports/                 # 导出产物
```

### 命名

用户可以修改画布名称。修改名称不改变画布 ID 和文件夹路径。

### 删除

删除画布时需要二次确认。

删除策略：

- 默认移动到应用回收站或系统回收站。
- 如果无法移动到回收站，提示用户确认永久删除。
- 删除操作不得影响其他画布文件夹。

### 导出

导出画布时生成一个可迁移包，包含：

- `canvas.json`
- `workflow.json`
- `history/`
- `prompts/`
- `assets/`

导出包不得包含：

- 真实 `apiToken`
- 私有密钥
- 本机绝对路径中的用户隐私信息，除非用户明确选择保留绝对路径

### 导入

导入画布时：

- 允许同名画布。
- 为导入画布生成新的随机 ID，除非用户选择保留原 ID。
- 校验资产文件是否存在。
- 不允许同名资产覆盖已有资产。
- 如果发现同名资产，生成新文件名并更新引用关系。
- 如果资产缺失，对应节点显示红色发光警告，并标识缺失资产路径。

## 资产引用与去重

资产引用支持三种形式：

- 相对路径：优先用于画布文件夹内资产，支持文件夹整体迁移。
- 绝对路径：用于引用用户本机外部文件。
- URL：用于远程资产或云端存储资产。

资产去重规则：

- 同一画布内不允许同名资产文件。
- 如果导入、拖入或生成资产时出现同名文件，系统自动生成不冲突文件名。
- 同一资产可被多个节点引用，不复制文件。
- 资产记录保存文件路径、URL、MIME、大小、校验值和来源任务。

## 供应商管理

### 供应商配置

用户可以维护供应商配置列表。每个供应商包含：

```ts
type ProviderConfig = {
  id: string;
  name: string;
  protocol: 'openai-compatible' | 'anthropic-compatible' | 'volcengine' | 'custom';
  baseURL: string;
  apiTokenRef: string;
  models: ProviderModelConfig[];
  enabled: boolean;
};
```

`apiTokenRef` 指向安全存储中的密钥，不直接保存明文 token。

### 模型配置与映射

供应商需要配置其支持的模型：

```ts
type ProviderModelConfig = {
  providerModelId: string;
  canonicalModelId: string;
  displayName?: string;
  billing?: BillingConfig;
  enabled: boolean;
};
```

示例：

```json
{
  "providerModelId": "image-2",
  "canonicalModelId": "gpt-image-2",
  "displayName": "第三方网关 image-2",
  "enabled": true
}
```

节点只使用项目标准模型 ID，例如 `gpt-image-2`。实际调用时由供应商适配器把标准模型 ID 映射为供应商模型 ID。

### 供应商筛选

节点选择供应商时，只展示存在本节点标准模型 ID 映射的供应商。

例如：

- `gpt-image-2` 图片节点只展示配置了 `canonicalModelId: "gpt-image-2"` 的供应商。
- `seedance2.0` 视频节点只展示配置了对应 Seedance 映射的供应商。

### 连通性测试

供应商配置页需要支持测试连接。

参考市面常见实现，测试连接应包含：

- `baseURL` 可访问。
- `apiToken` 可用。
- 可选：拉取模型列表。
- 可选：使用低成本请求验证模型可调用。
- 测试结果展示成功、失败原因、HTTP 状态码、供应商错误信息。

测试连接不得产生高成本生成任务，除非用户明确选择“测试模型生成”。

## 计费与用量

模型配置时可选择计费方式：

```ts
type BillingConfig =
  | {
      mode: 'official-token';
      inputTokenPrice?: number;
      outputTokenPrice?: number;
      currency?: string;
    }
  | {
      mode: 'per-call';
      pricePerCall?: number;
      currency?: string;
    }
  | {
      mode: 'none';
    };
```

要求：

- 如果配置了计费方式，每次生成记录需要保存用量和估算成本。
- 如果未配置计费方式，则不记录成本，只记录供应商返回的原始用量。
- 图片、视频按次计费或官方返回的用量计费。
- 对话节点按 token 计费。

## 画布内工作流管理

### 工作流配置

工作流配置包含：

- 节点列表
- 连线列表
- 节点参数
- 节点输入引用
- 节点输出资产
- 当前供应商选择
- 生成历史索引

每次大模型节点点击生成按钮后，必须：

1. 保存当前工作流配置。
2. 创建工作流快照。
3. 执行模型调用。
4. 保存提示词和输入引用。
5. 保存输出资产。
6. 更新节点输出。
7. 写入生成历史。

### 生成历史版本

每个大模型节点支持多次生成历史。

每次生成记录包含：

- 生成 ID
- 节点 ID
- 节点类型
- 模型 ID
- 供应商 ID
- 供应商模型 ID
- 输入提示词
- `@` 引用解析结果
- 输入资产列表
- 参数快照
- 工作流快照路径
- 输出资产列表
- 状态
- 错误信息
- 重试次数
- 开始时间
- 结束时间
- 用量和成本

用户可以查看历史版本，并把任意历史输出重新设为当前节点输出。

### 节点执行模式

一期支持：

- 单节点生成：只执行当前节点。
- 从当前节点向下游执行：执行当前节点及依赖其输出的后续节点。
- 全工作流执行：按依赖关系执行整个工作流。

后续再引入：

- 分支控制
- 循环控制
- 条件节点
- 批处理节点

### 队列与并发

大模型节点支持多次触发。

当节点已有任务正在运行时：

- 显示“再次触发”按钮。
- 再次触发会创建新的生成任务。
- 任务进入队列或并发执行，取决于全局并发配置。
- 节点当前输出默认使用最后一次成功结果。
- 历史记录保留所有触发结果。

全局需要支持：

- 最大并发数。
- 单供应商最大并发数。
- 单模型最大并发数。
- 排队任务取消。

## 节点管理

### 节点类型

一期节点：

- 图片模型节点：例如 `gpt-image-2`。
- 视频模型节点：例如 `seedance2.0`、`seedance2.0-fast`。
- 对话节点：OpenAI 格式或 Anthropic 格式语言模型。
- 资产展示节点：图片、视频、文件。

一个模型一个节点类型。例如：

- `gpt-image-2` 节点
- `seedance2.0` 节点
- `seedance2.0-fast` 节点

### 节点通用功能

所有大模型节点需要支持：

- 供应商选择。
- 参数配置。
- prompt 文本框。
- `@` 语法引用图片、视频、文件。
- 生成按钮。
- 再次触发按钮。
- 运行状态展示。
- 错误展示。
- 输出资产展示。
- 历史版本查看。

## `@` 引用能力

prompt 文本框支持 `@` 语法选择可接入本节点的资产。

引用对象包括：

- 图片节点输出
- 视频节点输出
- 文件资产
- 当前画布中的已有资产

不同节点根据模型能力限制可引用类型：

- 图片节点：图片、文件。
- 视频节点：图片、视频、音频、文件。
- 对话节点：文本、图片、文件；是否支持视频取决于供应商模型。

解析后保存：

```ts
type PromptReference = {
  token: string;
  assetId: string;
  nodeId?: string;
  path?: string;
  url?: string;
  kind: 'image' | 'video' | 'audio' | 'file' | 'text';
};
```

## 图片节点需求

### `gpt-image-2` 节点

功能：

- 输入 prompt。
- 支持供应商选择。
- 支持接入多个图片。
- 支持 `@` 引用图片和文件。
- 支持生成图片。
- 支持图片编辑。
- 支持多轮编辑。
- 支持多张输出。
- 输出图片保存到画布资产目录或 Cloudflare R2。

图片输入数量：

- OpenAI GPT image models 编辑输入最多支持 16 张图片。
- UI 应限制最多 16 张输入图。
- 第三方网关如果限制更低，供应商适配器应返回可读错误。

输出：

- 输出资产保存到 `assets/images/` 或云端对象存储。
- 节点记录输出资产 ID。
- 生成历史记录 prompt、输入图、模型参数和输出图。

## 视频节点需求

### `seedance2.0` / `seedance2.0-fast` 节点

功能：

- 输入 prompt。
- 支持供应商选择。
- 支持接入多个图片节点输出。
- 支持接入一个视频节点输出作为参考视频。
- 支持 `@` 引用图片、视频、音频、文件。
- 支持 callback 和轮询。
- 支持任务取消。
- 支持失败重试。
- 输出视频保存到画布资产目录或 Cloudflare R2。

失败重试：

- 默认开启。
- 默认最多重试 3 次。
- 用户可在节点或全局设置中关闭重试。
- 每次重试都写入生成历史。

callback：

- 支持用户自定义 callback URL。
- 默认尝试使用本机公网 IP 的 HTTP 地址。
- 如果 callback 不可用，回退轮询。
- callback 必须支持 secret 或签名校验。

## 对话节点需求

对话节点用于调用语言模型，支持 OpenAI 格式或 Anthropic 格式。

功能：

- 设置 system prompt。
- 设置 user prompt。
- 支持 `@` 引用图片、视频、文件。
- 支持供应商选择。
- 支持模型映射。
- 支持流式输出，若供应商支持。
- 保存每次对话输入、输出、用量和成本。

调用格式：

- OpenAI-compatible：messages / responses 风格。
- Anthropic-compatible：system + messages 风格。

## 存储要求

### 本地存储

本地存储是第一优先级。每个画布一个文件夹，保存该画布全部内容。

生成资产默认存储到画布文件夹下：

```text
assets/images/
assets/videos/
assets/files/
assets/covers/
```

### Cloudflare R2

云端对象存储第一期优先 Cloudflare R2。

R2 配置包含：

- accountId
- bucket
- endpoint
- accessKeyId
- secretAccessKey
- publicBaseURL
- 是否使用签名 URL

R2 密钥不得写入导出包或仓库。

## 失败恢复

应用重启后需要恢复未完成任务。

恢复规则：

- 启动时扫描运行中任务。
- 如果任务支持查询，则继续轮询。
- 如果任务有 callback，则保留 callback 状态等待。
- 如果任务超过最大等待时间，标记为失败。
- 如果开启重试，失败任务最多重试 3 次。
- 如果用户关闭重试，失败后只保留错误信息。

## 隐私与安全

- 导出画布不包含 apiToken。
- 导出画布不包含供应商密钥。
- 导出画布可以包含供应商 ID、模型映射和脱敏供应商名称。
- 本地配置中的 token 需要安全存储。
- 文档和日志不得打印完整 token。
- 远程 URL 下载失败时，不要泄露 token 到错误信息。

## 错误处理

需要覆盖：

- 供应商不可达。
- token 无效。
- 模型不存在。
- 模型映射缺失。
- 输入资产缺失。
- 输入资产类型不支持。
- 图片数量超限。
- 视频任务超时。
- callback 不可达。
- 存储失败。
- 导入资产冲突。

缺失资产展示：

- 节点显示红色发光警告。
- 节点详情显示缺失路径。
- 用户可以重新绑定资产。

## 验收标准

- 可以新建一个画布并生成唯一文件夹。
- 可以配置一个 OpenAI-compatible 供应商，并映射 `image-2` 到 `gpt-image-2`。
- `gpt-image-2` 节点只展示支持 `gpt-image-2` 的供应商。
- 图片节点最多允许选择 16 张输入图。
- 可以配置一个 Seedance 供应商，并映射标准版和 Fast 版。
- 视频节点可以引用多个图片节点和一个视频节点。
- 每次点击生成都会保存工作流快照、prompt、输入引用和输出资产。
- 同一个节点多次生成会产生多条历史版本。
- 失败任务默认最多重试 3 次，可关闭。
- 导入画布允许同名画布。
- 导入时同名资产不会覆盖。
- 缺失资产节点显示红色发光警告和缺失路径。
- 导出包不包含 apiToken。
- 本地项目目录移动后，相对路径资产仍可访问。
- 若配置 Cloudflare R2，生成资产可上传并通过稳定 URL 引用。
- 若配置计费，生成历史记录成本；若未配置计费，不记录成本。
